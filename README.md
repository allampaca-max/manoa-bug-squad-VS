# 마노아 벌레 서바이버

선크림 소녀와 알파카가 마노아 뒷마당에서 끝없이 몰려오는 벌레를 10분 동안 버티는 뱀파이어 서바이버류 게임. [마노아 벌레 퇴치단](https://github.com/allampaca-max/manoa-bug-squad) 카드 게임의 캐릭터와 그림을 그대로 가져왔다. 우리 집 이너서클 전용.

## 하는 법

- 화면 아무 데나 대고 끌면 그쪽으로 움직인다. 공격은 알아서 한다. PC에서는 WASD / 방향키, `P`나 `Esc`로 일시정지.
- 벌레가 떨어뜨린 보석을 주우면 레벨 업. 무기·아이템 중 하나를 고른다 (무기 4칸, 아이템 4칸, 최대 Lv 5).
- 날아다니는 바퀴벌레와 왕지네는 보물 상자를 떨어뜨린다. 무기가 Lv 5이고 짝이 되는 아이템이 있으면 상자에서 진화한다.
- 10:00에 바퀴벌레 대왕이 나온다. 잡으면 승리.

| 무기 | 하는 일 | 진화 (짝 아이템) |
|---|---|---|
| 스프레이 (소녀 시작) | 가까운 벌레 쪽으로 분사 | 연막 소독 (하와이 차) |
| 침 뱉기 (알파카 시작) | 가까운 벌레에게 침 | 침 폭풍 (스팸 무스비) |
| 슬리퍼 | 던지면 부메랑처럼 돌아옴 | 쪼리 폭풍 (하얀 운동화) |
| 양산 | 몸 주위를 빙글빙글 | 비치 파라솔 (털 뭉치) |
| 선크림 | 몸 둘레 막, 닿으면 피해 | SPF 100 (포옹) |
| 레이드 | 화면 속 아무 벌레에게 폭발 | 무지개 폭격 (무지개) |
| 알파카 돌격 | 알파카 친구가 화면을 가로질러 달림 | 알파카 대이동 (스팸 무스비) |

## 실행

바로 하기: https://allampaca-max.github.io/manoa-bug-squad-VS/ (GitHub Pages, `main`에 푸시하면 1~2분 뒤 반영)

빌드 없이 `index.html`과 `sprites/` 폴더로 돌아간다. 폰에서 "홈 화면에 추가"하면 앱처럼 전체 화면으로 열린다.

## 밸런스 고치기

`index.html` 스크립트 맨 위 `DATA` 부분에 다 모여 있다.

- `HEROES`: 체력, 이동 속도, 시작 무기
- `WEAPONS`: 레벨별 강화(`lv`)와 진화(`evo`), `PASSIVES`: 아이템
- `ENEMIES`: 벌레 체력·속도·공격력·경험치
- `WAVES`: 분마다 화면에 유지할 벌레 수와 종류, `EVENTS`: 떼·포위·엘리트·보스 등장 시각
- `xpNeed`: 레벨 업에 필요한 경험치
- `SPRITES`: 캐릭터 그림(`sprites/`)과 애니메이션 재생 순서

## Claude 아티팩트로 게시

```sh
scripts/build-artifact.sh   # → dist/artifact.html
```

게시할 때 `sprites/` 아래 PNG(`sprites/icons/` 포함)도 같은 경로로 같이 올린다.

현재 아티팩트: https://claude.ai/artifact/DvVrra8fWqhNZAaaYu5q3B
