# 마노아 벌레 서바이버

선크림 소녀와 알파카, 그리고 우리 집 세탁실 게코가 마노아 뒷마당에서 끝없이 몰려오는 벌레를 10분 동안 버티는 뱀파이어 서바이버류 게임. [마노아 벌레 퇴치단](https://github.com/allampaca-max/manoa-bug-squad) 카드 게임의 캐릭터와 그림을 그대로 가져왔다. 우리 집 이너서클 전용.

## 하는 법

- 메인 화면 → 시작하기 → 캐릭터 고르기 → 스테이지 고르기 → 출발. 기록 화면에 스테이지·캐릭터별 최고 기록과 누적 판 수가 남는다.
- 화면 아무 데나 대고 끌면 그쪽으로 움직인다. 공격은 알아서 한다. PC에서는 WASD / 방향키, `P`나 `Esc`로 일시정지.
- 벌레가 떨어뜨린 보석을 주우면 레벨 업. 무기·아이템 중 하나를 고른다 (무기 4칸, 아이템 4칸, 최대 Lv 5).
- 날아다니는 바퀴벌레와 왕지네는 보물 상자를 떨어뜨린다. 무기가 Lv 5이고 짝이 되는 아이템이 있으면 상자에서 진화한다.
- 스테이지마다 10:00에 최종 보스가 나온다. 잡으면 승리.
  - **마노아 뒷마당**: 바퀴벌레·개미·모기·지네·달팽이, 엘리트 날아다니는 바퀴벌레, 5분 왕지네, 10분 바퀴벌레 대왕.
  - **우리 집 세탁실**: 세탁기·건조기·빨래 바구니·세제통은 지나갈 수 없다 (날아다니는 벌레는 넘어온다). 좀벌레·나방·흰개미 떼, 엘리트 카네 거미, 5분 대왕 카네 거미, 10분 흰개미 여왕 (흰개미를 계속 낳는다).
- 소리: 타이틀·전투·보스 배경음과 효과음 (전부 코드로 합성한 칩튠). 타이틀이나 일시정지 화면에서 효과음·배경음을 따로 끌 수 있다. 아이폰은 무음 모드면 소리가 안 난다.
- **동전과 상점**: 벌레가 가끔 동전을 떨어뜨리고, 엘리트·보스·보물 상자는 한 움큼 준다. 판이 끝나면 (져도) 버틴 시간만큼 보너스를 얹어 지갑에 모인다. 메인 화면 상점에서 최대 체력·힘·이동 속도 같은 영구 강화와 레벨 업 도우미(다시 뽑기·건너뛰기·빼 버리기), "한 번 더"(부활)를 산다. 언제든 전부 되돌려 받을 수 있다.
- **틈 (하드 모드)**: 낡은 집이라 어디에 틈이 있는지 모른다. 스테이지 화면에서 틈 단계(0~5)를 고르면 벌레가 더 많이, 더 세게 나오고 동전도 더 준다. 아무 스테이지나 틈 N에서 깨면 틈 N+1이 열린다.
- 게코는 체력이 적고 빠르다. 혀로 잡아먹으면 체력이 조금 차고, 한 번은 꼬리를 떼어 주고 살아난다 (그동안 벌레들은 꼬리를 쫓아간다).

| 무기 | 하는 일 | 진화 (짝 아이템) |
|---|---|---|
| 스프레이 (소녀 시작) | 가까운 벌레 쪽으로 분사 | 연막 소독 (하와이 차) |
| 침 뱉기 (알파카 시작) | 가까운 벌레에게 침 | 침 폭풍 (스팸 무스비) |
| 슬리퍼 | 던지면 부메랑처럼 돌아옴 | 쪼리 폭풍 (하얀 운동화) |
| 양산 | 몸 주위를 빙글빙글 | 비치 파라솔 (털 뭉치) |
| 선크림 | 몸 둘레 막, 닿으면 피해 | SPF 100 (포옹) |
| 레이드 | 화면 속 아무 벌레에게 폭발 | 무지개 폭격 (무지개) |
| 알파카 돌격 | 알파카 친구가 화면을 가로질러 달림 | 알파카 대이동 (스팸 무스비) |
| 끈끈이 혀 (게코 시작) | 가까운 벌레에게 혀, 잡아먹으면 체력 | 게코 일가족 (게코 알) |

## 실행

바로 하기: https://allampaca-max.github.io/manoa-bug-squad-VS/ (GitHub Pages, `main`에 푸시하면 1~2분 뒤 반영)

빌드 없이 `index.html`과 `sprites/` 폴더로 돌아간다. 폰에서 "홈 화면에 추가"하면 앱처럼 전체 화면으로 열린다.

## 밸런스 고치기

`index.html` 스크립트 맨 위 `DATA` 부분에 다 모여 있다.

- `HEROES`: 체력, 이동 속도, 시작 무기
- `STAGES`: 스테이지마다 웨이브·이벤트·바닥. `ready: false`면 스테이지 화면에 "준비 중"으로 잠겨 보인다
- `WEAPONS`: 레벨별 강화(`lv`)와 진화(`evo`), `PASSIVES`: 아이템
- `ENEMIES`: 벌레 체력·속도·공격력·경험치
- `WAVES`: 분마다 화면에 유지할 벌레 수와 종류, `EVENTS`: 떼·포위·엘리트·보스 등장 시각
- `xpNeed`: 레벨 업에 필요한 경험치
- `DROPS` / `COINS`: 동전 나오는 양, `UPGRADES`: 상점 강화 (가격 = `cost` × 다음 레벨), `gapMods`: 틈 단계마다 세지는 정도
- `SONGS`: 배경음 악보 (8분음표 한 칸씩, 마디마다 코드), `SFX`: 효과음과 음량(`vol`), `MIX`: 전체 음량
- `SPRITES`: 캐릭터 그림(`sprites/`)과 애니메이션 재생 순서, `PROP_ART`: 그림이 있는 아이템·투사체

## 그림 추가하기

그림은 Codex 이미지 생성으로 만들고 `scripts/pixelize.py`로 게임 크기에 맞춘다. 순서와 프롬프트 틀은 `art/CODEX.md`.

## Claude 아티팩트로 게시

```sh
scripts/build-artifact.sh   # → dist/artifact.html
```

게시할 때 `sprites/` 아래 PNG(`sprites/icons/` 포함)도 같은 경로로 같이 올린다.

현재 아티팩트: https://claude.ai/artifact/DvVrra8fWqhNZAaaYu5q3B
